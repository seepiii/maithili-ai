# Training sentences for chat_cli.py

Work through these with `python3 chat_cli.py` — type each sentence, correct
it if the AI's version is wrong (`c`), let it explain why. Check off as you
go. Grouped by grammar feature so the correction corpus ends up covering
Maithili broadly, not just whatever you happen to say day-to-day.

Maithili has multiple honorific registers (roughly: tohar/tu = very
informal, tora/ahā̃ = familiar/respectful, apne = most formal) — when you
correct a sentence, it's worth noting in your head which register you used,
since the "why" explanation should surface that.

- [ ] You are going home (said to a younger sibling)
- [ ] You are going home (said to your grandfather)
- [ ] He/she is my friend
